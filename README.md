# PokemonEDA

Exploratory Data Analysis of Pokemon statistics using Python and Apache Spark.

## Project Description

This project analyzes Pokemon statistics to identify offensive candidates and support Pokemon for a game event.

## Dataset Source

Kaggle - Pokemon Stats Dataset:

https://www.kaggle.com/datasets/shreyashautomation/pokemon-stats-dataset

## Technologies

- Python
- Apache Spark
- PySpark
- Pandas
- Matplotlib

## Project Files

- `pokemon_eda.py`: Data processing and exploratory analysis.
- `dataset_download.py`: Dataset download script.
- `data/`: Original dataset.
- `top_5_attack.png`: Offensive Pokemon visualization.
- `support_pokemon.png`: Support Pokemon visualization.

## Execution

Run the analysis with:

```bash
python3 pokemon_eda.py
